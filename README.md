# Mensajería Total — Syntax Logistics

> Equipo: Syntax Error | Junio 2026

## Descripción

Plataforma web profesional para Mensajería Total, empresa especializada
en el traslado y entrega de paquetería, documentos y mercancía ligera
en la Ciudad de México y Área Metropolitana.

El sitio presenta los servicios de la empresa, permite cotizar envíos,
rastrear paquetes y contactar al equipo, todo bajo un diseño responsivo
y consistente definido en Figma.

## 🛠 Tecnologías

- HTML5 + CSS3 + JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Vite
- Git / GitHub
- Figma (diseño)


## Cómo correr el proyecto localmente

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```
